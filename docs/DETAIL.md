# 会话删除 (Session delete)

在侧栏会话的右键菜单里新增一项 **「删除会话…」**，永久删除该会话及其对话日志。

## 与「归档」的区别（重要）

DSH 内置的 **归档 (Archive)** 与这里的 **删除 (Delete)** 是两个独立动作，本插件不会把两者混在一起：

| | 归档（内置） | 删除（本插件） |
|---|---|---|
| 效果 | 从侧栏隐藏 | 从磁盘移除 |
| 会话日志 | 完整保留 | 永久删除 |
| 是否可恢复 | 可以取消归档恢复 | **不可撤销** |
| 磁盘空间 | 不释放 | 释放 |

想隐藏就归档；想彻底清掉才用删除。

## 使用方式

1. 在左侧会话列表中，把鼠标移到目标会话上，点行尾的 **「…」** 菜单。
2. 选择 **「删除会话…」**。
3. 确认框中会显示该会话标题，确认后立即删除。

## 安全防护

- **删除前必须确认**：确认框显示会话标题，并明确提示不可撤销。
- **运行中的会话禁止删除**：正在执行的会话会被拒绝，请先停止它，避免在日志仍被写入时删除导致数据损坏。
- **只删自己范围内的数据**：Host 端只删除解析后仍位于会话根目录内的路径，构造的请求无法越界删除其他目录。

## 删除的到底是什么

会话以「一个会话一个目录」的形式存放：

```
~/.dsh/sessions/<工作区编码>/<会话ID>/
  session.v4.jsonl.zstd   对话日志
  session.lock            写入锁文件（无数据）
```

删除即移除该会话目录。会话列表是扫描该目录树得到的，所以删除后无需额外重建索引。

## 限制

- 一旦删除无法恢复，也没有回收站。
- 被删除会话的附件等关联数据不会被连带清理。
- 建议只在确认不再需要该会话时使用。
